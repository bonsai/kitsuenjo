# kitsuenjo

**偶然居合わせた人同士に、会話が生まれる場所。**

kitsuenjo（喫煙所）は、同じ場所にたまたま居合わせた人が、気軽にひと言を交わせる体験を考えるプロジェクトです。喫煙を推奨するサービスではなく、「喫煙所でふと会話が始まる」ような、目的や所属を前提としない交流のあり方を発想の起点にします。

> **コンセプト：話すつもりがなくても、会話が始まる。**

## 解決したいこと

オンラインの交流は、参加登録や共通の関心、継続的な関係が前提になりがちです。一方で、日常には、たまたま隣り合った人との短い会話から気づきや発見が生まれる瞬間があります。

kitsuenjo は、そうした**偶発的で、短くてもよい会話**の体験を探ります。

## 体験の原則

- **参加のハードルを低くする：** 話す・聞く・立ち去る自由を尊重する。
- **短い会話を歓迎する：** 継続的な交流やプロフィール作成を必須にしない。
- **無理に会話を成立させない：** 沈黙や退出も自然な選択肢にする。
- **安全とプライバシーを守る：** 個人情報の詮索、嫌がらせ、執拗な接触を防ぎ、通報・退出手段を検討する。
- **喫煙を参加条件にしない：** 名前は比喩的な着想であり、喫煙場所への誘導や喫煙行為を目的としない。

## 想定する体験（仮説）

1. その場に参加する。
2. 話題や問いかけをきっかけに、会話が始まることがある。
3. 話したい人は話し、聞くだけの人は聞き、いつでも退出できる。
4. 会話はその場で完結してもよく、関係の継続を求めない。

これは現時点のコンセプト仮説です。オンラインで実現するのか、現実の場を支援するのか、具体的な体験設計や実装方式は今後検証します。
